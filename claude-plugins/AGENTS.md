# Plugin source

For agent instructions, apply the applicable plugin's authoring discipline. Fabrika
uses `writing-for-agents` and its `docs/skill-conventions.md`; its contract files
are read by the needed heading, never whole. Keep judgment in skills and deterministic
work in callable verbs. Instructions and examples must match the actual verb contract.

Fabrika installs in other repositories. References in its shipped files must resolve
with the plugin alone; do not add Phoenix-only names or links there. Check neighboring
skill descriptions when changing triggers so responsibilities remain distinct.

Use the shared [pattern index](../.patterns/index.md) for repository guidance.
Plugin-owned conventions remain in the plugin, not copied into this file.
