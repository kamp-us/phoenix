# fabrika CLI interface convention + contract-spec format

This page served two audiences in one file and has split into two single-mode reference pages
(#7021):

- **[The CLI interface convention](interface-convention.md)** — the interface every fabrika verb
  owes its caller: `--help` discoverability, stdout discipline, exit-status semantics,
  fail-closed scope behavior, literal invocation strings, and delivery.
- **[The contract-spec format](contract-spec.md)** — the shape of the `contract.md` an authoring
  session derives for the verbs its skill needs: required sections, the completeness test, and a
  worked example.

Links that name this path still land here; point them at whichever of the two pages carries what
you mean.
