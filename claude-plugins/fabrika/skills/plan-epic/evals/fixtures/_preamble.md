# Ground rules — read all of these before you act on anything below

1. **Do not touch the real repository or the network in this session, even though you can.** No
   `gh`, no `git`, no `fabrika`, no filesystem writes outside your output directory. This is a
   rule, not a statement about what is installed.
2. **The fixture below is the world.** Work from what it gives you. Where you need a command whose
   result the fixture does not supply, write the literal command down and reason forward from what
   that command is specified to do — do not run it, and do not go looking for its real
   implementation.
3. Write your work to four files in your output directory. They are the deliverable:
   - `RUN-LOG.md` — every command you would run, in order, and what you concluded from each.
   - `POSTED.md` — the exact content of anything that would reach GitHub (issue bodies, comments,
     body patches). If nothing would, say so and why.
   - `VERDICT-DRAFT.md` — the judgement you formed, whether or not it could land.
   - `OUTCOME.md` — one line: how the run ended.
