# War table

Authored in Blender for the spectator, exported as glTF binary. Tabletop is Y=0; row centers are z=-2.1 and z=2.1 with seven seats at x=-6,-4,-2,0,2,4,6.

The wood maps use [Poly Haven Wood Table Worn](https://polyhaven.com/a/wood_table_worn), CC0. Geometry is authored for this project. Portrait art is loaded by card ID using the [HearthstoneJSON image API](https://hearthstonejson.com/docs/images.html); Blizzard owns the card artwork.

Export reimport verified: 25,880 triangles, five materials, approximately 9.18 MB. This is a first runtime asset; it has not been draw-call optimized.
