# Workspace packages

Every workspace package here needs a README stating what it is, why it exists and
how to use it. Keep shared packages independent of app-specific vocabulary unless
their declared purpose requires it.

Check `fabrika --help` and the relevant group's help before writing new tracker or
git orchestration.

Read the owning package's README and use the shared
[pattern index](../.patterns/index.md) for the relevant implementation guidance.
